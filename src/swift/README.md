# SASD Notes — Swift implementation

This directory is reserved for a future Swift implementation of SASD Notes, most likely targeting macOS with a native Apple UI stack.

The Swift version is not part of the current V1 scope.

When development begins, document the minimum macOS version, Swift/Xcode baseline, UI framework, package structure, sandbox/file-access strategy, and test framework here.

The implementation must follow the shared product contracts in `/spec` and operate on portable Markdown vaults.
