# SASD Notes — C++ implementation

This directory is reserved for a future native C++ implementation of SASD Notes.

No C++ implementation is required for V1 of the current .NET application.

When development begins, prefer an idiomatic C++ project layout and document the selected UI toolkit, supported operating systems, compiler baseline, build system, and test framework here.

The implementation must follow the shared product contracts in `/spec` and preserve compatibility with normal Markdown vaults.

A future C++ implementation should receive its own `AGENTS.md` once its toolchain and architecture are selected.
