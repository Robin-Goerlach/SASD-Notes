# SASD Notes — Java implementation

This directory is reserved for a future Java implementation of SASD Notes.

The Java version is not part of the current V1 scope.

When development begins, document the selected JDK baseline, desktop UI framework, build tool, packaging strategy, and test framework here.

The implementation must follow the shared product contracts in `/spec` and keep the Markdown vault format interoperable with the other SASD Notes implementations.
