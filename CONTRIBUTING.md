# Contributing

This repository is currently prepared as a starter for the SASD Notes project.

## Working style

- keep the architecture layered
- prefer readable code over clever code
- document decisions
- add tests for parser, search and file handling logic
- keep Markdown files as the primary source of truth

## Documentation first

Before implementing major feature blocks, update the relevant documents in `docs/`.

## Commit style

Examples:

- `feat(vault): add root folder loading`
- `feat(editor): add markdown formatting helpers`
- `fix(search): improve result snippet generation`
- `docs: update technical design and test handbook`
