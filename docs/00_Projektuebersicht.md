# SASD Notes – Repository Starter

Version: 0.1  
Date: 2026-07-04  
Status: Documentation starter repository

## Purpose

This repository starter bundles the initial planning and architecture documents for **SASD Notes**.

SASD Notes is planned as a Windows desktop application for managing local Markdown knowledge bases with internal links, structured folders, search, backlinks and editor-oriented workflows. The first technical implementation target is **Windows Forms on .NET 8**, with later room for richer UI variants and a future plugin system.

## Included content

- product vision and scope
- Obsidian-oriented feature reference catalog
- requirements and design documents
- security, testing, development and operations guidance
- repository skeleton for `src/`, `tests/` and `docs/`
- concept screenshot for the intended desktop UI

## Intended use

This starter is meant to be uploaded as the initial content of a GitHub repository and then evolved into the real implementation project.
